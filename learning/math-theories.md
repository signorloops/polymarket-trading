## 1. 预测市场基础

> 源码: `src/strategies/simple-arbitrage.ts`, `src/market/arbitrage-detector.ts`

### 1.1 二元结果市场

Polymarket 是一个**预测市场**（Prediction Market），每个市场对应一个未来事件，有 YES 和 NO 两个结果代币。

```
┌─────────────────────────────────────────────┐
│           预测市场："明天会下雨吗？"            │
│                                             │
│   YES 代币  ←→  价格 = 事件发生的隐含概率      │
│   NO  代币  ←→  价格 = 事件不发生的隐含概率     │
│                                             │
│   核心约束:  P(YES) + P(NO) = 1              │
│                                             │
│   结算规则:  事件发生 → YES = $1, NO = $0     │
│             事件不发生 → YES = $0, NO = $1    │
└─────────────────────────────────────────────┘
```

### 1.2 价格即概率

市场价格**直接映射**到隐含概率：

```
价格 θ ∈ [0, 1]  ⟺  隐含概率 P = θ
```

**例子**：如果 YES 代币价格 = 0.70，意味着市场认为该事件有 70% 概率发生。

### 1.3 单市场套利

当 YES + NO 的价格之和偏离 1 时，出现套利机会：

```
情况 1: YES + NO < 1  （定价偏低）
────────────────────────────
  买入 YES + 买入 NO = 花费 (YES + NO)
  无论结果如何，获得 $1
  利润 = 1 - (YES + NO) > 0

情况 2: YES + NO > 1  （定价偏高）
────────────────────────────
  卖出 YES + 卖出 NO = 收入 (YES + NO)
  无论结果如何，赔付 $1
  利润 = (YES + NO) - 1 > 0
```

**数值例子**：

```
YES 价格 = $0.45
NO  价格 = $0.48
────────────────
总和 = $0.93 < $1.00

操作: 各买 100 份
花费: 100 × $0.93 = $93
结算: 无论结果 → 100 × $1.00 = $100
利润: $100 - $93 = $7 (7.5% 回报)
```

### 1.4 隐含概率

```
impliedProbability = yesPrice / (yesPrice + noPrice)
```

**例子**：YES = $0.45, NO = $0.48 → 隐含概率 = 0.45 / 0.93 ≈ 48.4%

## 2. 信息论：KL 散度

> 源码: `src/utils/math.ts` (L114-175)

### 2.1 KL 散度（Kullback-Leibler Divergence）

KL 散度衡量两个概率分布之间的"距离"。在本项目中，它衡量**市场价格的错误程度**。

**标准 KL 散度**：

```
D_KL(P || Q) = Σᵢ Pᵢ · log(Pᵢ / Qᵢ)
```

其中 P 是"真实"分布（投影），Q 是市场价格分布。

```
直觉图解:

  P (投影/真实)    Q (市场价格)        D_KL
  ┌──────┐        ┌──────┐
  │ 0.60 │        │ 0.45 │   0.60 × log(0.60/0.45) = 0.172
  │ 0.40 │        │ 0.55 │   0.40 × log(0.40/0.55) = -0.128
  └──────┘        └──────┘   ─────────────────────────────
                              D_KL = 0.172 + (-0.128) = 0.044
```

**关键性质**：
- `D_KL(P || Q) ≥ 0`，当且仅当 P = Q 时等号成立
- **不对称**: `D_KL(P || Q) ≠ D_KL(Q || P)`
- 捕捉的是**相对误差**，不是绝对误差

### 2.2 为什么用 KL 散度而不是欧几里得距离？

```
场景对比（价格从 θ₁ 变到 θ₂）:

  场景 A: 0.05 → 0.10  (翻倍!)
  场景 B: 0.50 → 0.55  (增长 10%)

  欧几里得距离:  |0.10 - 0.05| = |0.55 - 0.50| = 0.05  (相同!)
  KL 散度:       0.10·log(0.10/0.05) = 0.069
                 0.55·log(0.55/0.50) = 0.052          (A 更大!)

  结论: KL 散度正确反映了低概率事件的价格变化更有意义
```

### 2.3 广义 KL 散度

> 源码: `src/utils/math.ts` (L153-175)

用于**非归一化**的向量（跨市场套利时，概率不一定加和为 1）：

```
D_GKL(P || Q) = Σᵢ [Pᵢ · log(Pᵢ / Qᵢ) - Pᵢ + Qᵢ]
```

额外的 `-Pᵢ + Qᵢ` 项惩罚总量不匹配。

**数值例子**：

```
P = [0.3, 0.3]  (总和 0.6)
Q = [0.4, 0.5]  (总和 0.9)

标准 KL:   0.3·log(0.3/0.4) + 0.3·log(0.3/0.5) = -0.086 + (-0.153) = -0.239  ← 负数！不对
广义 KL:   (-0.086 - 0.3 + 0.4) + (-0.153 - 0.3 + 0.5) = 0.014 + 0.047 = 0.061  ← 正数 ✓
```

### 2.4 Softmax 与 Log-Sum-Exp

> 源码: `src/utils/math.ts` (L181-198)

**Softmax** 把任意实数转换为概率分布：

```
softmax(xᵢ) = exp(xᵢ) / Σⱼ exp(xⱼ)

例子: x = [2.0, 1.0, 0.1]
      exp(x) = [7.389, 2.718, 1.105]
      sum = 11.212
      softmax = [0.659, 0.242, 0.099]  ← 和为 1 ✓
```

**Log-Sum-Exp** 技巧防止数值溢出：

```
log(Σ exp(xᵢ)) = max(x) + log(Σ exp(xᵢ - max(x)))

例子: x = [1000, 1001, 999]
      直接计算: exp(1000) = ∞  ← 溢出!
      技巧:     max = 1001
                exp([1000-1001, 1001-1001, 999-1001])
              = exp([-1, 0, -2])
              = [0.368, 1.0, 0.135]
              = 1001 + log(1.503) = 1001.407  ✓
```

## 3. 凸优化：Frank-Wolfe 算法

> 源码: `src/core/frank-wolfe.ts`

### 3.1 问题定义

**目标**：在可行域（边际多面体 M）中找到离市场价格最近的合法概率分布。

```
    min   D_KL(μ || θ)
    μ∈M

其中:
  μ = 我们要找的合法概率分布（投影）
  θ = 当前市场价格向量
  M = 边际多面体（所有合法概率分布的集合）
```

**为什么要做这个优化？** 如果市场价格 θ 不在 M 内（即存在不一致），那么最优 μ* 与 θ 的差异就是**套利方向**。

### 3.2 算法流程

```
┌─────────────────────────────────────────────────────────┐
│                  Frank-Wolfe 算法                        │
│                                                         │
│  输入: 初始点 μ₀, 目标函数 f(μ), 约束集 M              │
│                                                         │
│  for t = 0, 1, 2, ... :                                │
│    ① 计算梯度:  ∇f(μₜ) = log(μₜ/θ) + 1               │
│                                                         │
│    ② LMO 求解:  sₜ = argmin  ⟨∇f(μₜ), v⟩             │
│                       v ∈ M                             │
│                                                         │
│    ③ 计算间隙:  gap = ⟨∇f(μₜ), μₜ - sₜ⟩              │
│                                                         │
│    ④ 收敛检查:  if gap ≤ tol × (1-α) × |f(μₜ)|       │
│                    → 返回 μₜ                            │
│                                                         │
│    ⑤ 线搜索:    γₜ = argmin f((1-γ)μₜ + γsₜ)         │
│                       γ∈[0,1]                           │
│                                                         │
│    ⑥ 更新:      μₜ₊₁ = (1-γₜ)μₜ + γₜsₜ              │
│                                                         │
│  输出: μ* (最优分布), 目标值, 间隙                       │
└─────────────────────────────────────────────────────────┘
```

### 3.3 Frank-Wolfe 间隙（Gap）

间隙是对"距离最优解有多远"的**上界**：

```
f(μₜ) - f(μ*) ≤ gapₜ = ⟨∇f(μₜ), μₜ - sₜ⟩
```

**在套利中的意义**：

```
保证利润 = 目标值 - 间隙

        目标值 (D_KL)              间隙 (Gap)
    ┌─────────────────┬──────────────────┐
    │  确定可获得的利润  │  可能额外获得的   │
    │  (保守估计)       │  利润（不确定）    │
    └─────────────────┴──────────────────┘
    0               保证利润           目标值

例子:
  D_KL = 0.08,  Gap = 0.02
  保证利润 = 0.08 - 0.02 = 0.06
  → 至少能获得 $0.06/份 的利润
```

### 3.4 数值例子

```
市场: 2 个事件，每个有 YES/NO
  事件 A:  YES = $0.40, NO = $0.50  (和 = 0.90, 偏低)
  事件 B:  YES = $0.55, NO = $0.50  (和 = 1.05, 偏高)

价格向量 θ = [0.40, 0.50, 0.55, 0.50]

约束:
  θ₁ + θ₂ = 1  (事件 A)
  θ₃ + θ₄ = 1  (事件 B)

Frank-Wolfe 迭代:
  初始 μ₀ = [0.50, 0.50, 0.50, 0.50]  (均匀分布)

  迭代 1:
    梯度 = log(μ/θ) + 1 = [1.223, 1.000, 0.909, 1.000]
    LMO 选择梯度最小的分量 → s = [0, 0, 1, 0]
    gap = ⟨grad, μ-s⟩ = 0.157
    γ = 0.3 (线搜索)
    μ₁ = 0.7 × [0.50, 0.50, 0.50, 0.50] + 0.3 × [0, 0, 1, 0]
        = [0.35, 0.35, 0.65, 0.35]

  ... 经过多次迭代 ...

  最终 μ* ≈ [0.44, 0.56, 0.52, 0.48]

  套利方向 = μ* - θ = [+0.04, +0.06, -0.03, -0.02]
  解读: 买入 A-YES, 买入 A-NO, 卖出 B-YES, 卖出 B-NO
```

### 3.5 Barrier Frank-Wolfe（屏障变体）

> 源码: `src/core/frank-wolfe.ts` (L220-332)

加入**屏障项**处理不等式约束，防止解落在边界上：

```
min  f(μ) + ε · B(μ)
μ∈M

其中 B(μ) = -Σ log(μᵢ)  是对数屏障函数

ε 自适应收缩:
  if gap/(-4·gapU) < ε:
    ε ← min(gap/(-4·gapU), ε/2)

直觉: ε 逐渐变小，屏障效应减弱，解越来越接近真实最优
```

## 4. 边际多面体与约束

> 源码: `src/core/marginal-polytope.ts`, `src/market/constraint-builder.ts`

### 4.1 什么是边际多面体？

边际多面体 M 是所有**合法概率分布**的集合：

```
M = { μ ∈ R^n :  Σⱼ μⱼ = 1   (每个事件的结果概率和为 1)
                 0 ≤ μⱼ ≤ 1  (概率在 [0,1] 范围内) }
```

**图解（2 个结果的情况）**：

```
  μ₂
  1 ┤╲
    │  ╲
    │    ╲  ← 边际多面体 M（概率单纯形）
    │      ╲    所有点满足 μ₁ + μ₂ = 1
    │        ╲
  0 ┤─────────╲──── μ₁
    0          1

  例: μ = (0.6, 0.4) 在 M 内  ✓
      μ = (0.7, 0.5) 不在 M 内 ✗ (和 = 1.2 ≠ 1)
```

**多事件情况**：

```
  事件 A: 3 个结果 (a₁, a₂, a₃)  →  a₁ + a₂ + a₃ = 1
  事件 B: 2 个结果 (b₁, b₂)      →  b₁ + b₂ = 1

  M = { (a₁,a₂,a₃,b₁,b₂) : a₁+a₂+a₃=1, b₁+b₂=1, 全部≥0 }

  这是两个单纯形的 笛卡尔积
```

### 4.2 约束类型

```
┌────────────────┬──────────────────────────┬─────────────────┐
│ 约束类型        │ 数学表达                  │ 含义             │
├────────────────┼──────────────────────────┼─────────────────┤
│ 概率和          │ Σ μᵢ = 1 (每事件)        │ 结果互斥且穷尽    │
│ 非负性          │ μᵢ ≥ 0                   │ 概率不能为负      │
│ 上界            │ μᵢ ≤ 1                   │ 概率不超过 1      │
│ 互斥            │ P(A) + P(B) ≤ 1          │ A、B 不能同时发生 │
│ 蕴含            │ P(A) ≤ P(B)              │ A 发生则 B 必发生 │
│ 条件概率        │ P(child) ≤ P(parent)     │ 子事件概率≤父事件  │
└────────────────┴──────────────────────────┴─────────────────┘
```

### 4.3 可行性检查

```
对于等式约束 Σ cᵢ · μᵢ = rhs:
  |Σ cᵢ · μᵢ - rhs| ≤ tolerance  → 满足

对于不等式约束 Σ cᵢ · μᵢ ≥ rhs:
  Σ cᵢ · μᵢ ≥ rhs - tolerance  → 满足
```

## 5. 线性最小化预言机 (LMO)

> 源码: `src/core/lmo.ts`

### 5.1 LMO 的作用

Frank-Wolfe 的核心子问题：在可行域 M 中找到**最小化梯度内积的顶点**。

```
s = argmin  ⟨∇f(μ), v⟩
    v ∈ M
```

### 5.2 快速路径：积单纯形

当约束只有等式约束（每事件概率和 = 1）时，问题可以**分解**：

```
对每个事件独立求解:

  事件 k 有结果集 Sₖ = {i₁, i₂, ..., iₘ}
  约束: Σⱼ∈Sₖ cⱼ · vⱼ = rhsₖ

  最优选择: 找 score 最小的分量
  score(j) = gradient(j) / coefficient(j)

  best = argmin score(j)
        j ∈ Sₖ

  vertex[best] = rhs / coefficient[best]
  vertex[其他] = 0
```

**图解**：

```
事件 A (3 个结果): 梯度 = [2.1, 0.8, 1.5]
                  系数   = [1,   1,   1  ]
                  score  = [2.1, 0.8, 1.5]
                            ↑
                         最小 → 选 a₂
                  vertex = [0, 1, 0]

事件 B (2 个结果): 梯度 = [1.2, 0.3]
                  score  = [1.2, 0.3]
                            ↑
                         最小 → 选 b₂
                  vertex = [0, 1]

完整 vertex = [0, 1, 0, 0, 1]

复杂度: O(n) 而非 LP 求解的 O(n³)
```

## 6. 线搜索算法

> 源码: `src/core/line-search.ts`

### 6.1 黄金分割搜索

找到最优步长 γ ∈ [0, 1]，使得沿搜索方向的目标函数最小：

```
γ* = argmin  f((1-γ)μ + γs)
     γ∈[0,1]
```

**黄金比例**: φ = (√5 - 1) / 2 ≈ 0.618

```
算法流程:

  [left ─────────────────────────── right]
       x₁              x₂
       ↑                ↑
  right - φ·(r-l)  left + φ·(r-l)

  if f(x₁) > f(x₂):
    left ← x₁       [丢弃左侧]
  else:
    right ← x₂      [丢弃右侧]

  重复直到 right - left < 10⁻⁸
```

**数值例子**：

```
初始: [0, 1]
φ = 0.618

迭代 1: x₁ = 1 - 0.618·1 = 0.382
         x₂ = 0 + 0.618·1 = 0.618
         f(0.382) = 0.0234
         f(0.618) = 0.0189  ← 更小
         → left = 0.382, 区间 = [0.382, 1]

迭代 2: x₁ = 1 - 0.618·0.618 = 0.618
         x₂ = 0.382 + 0.618·0.618 = 0.764
         f(0.618) = 0.0189
         f(0.764) = 0.0256  ← 更大
         → right = 0.764, 区间 = [0.382, 0.764]

... 继续迭代 ...

最终: γ* ≈ 0.55
```

**为什么用黄金分割而不是牛顿法？**
- **无导数**: 不需要计算二阶导数
- **鲁棒**: 对噪声价格数据更稳定
- **保证收敛**: 对单峰函数一定收敛

### 6.2 二次近似线搜索

更快但精度较低的方法（作为备选）：

```
γ = -⟨∇f, d⟩ / ⟨d, d⟩

其中 d = s - μ 是搜索方向

直觉: 假设目标函数沿 d 方向是二次的，直接跳到最低点
```

### 6.3 自适应步长

```
γ(t) = 2 / (t + 2)

  t=0: γ = 1.000  ← 初始大步长
  t=1: γ = 0.667
  t=5: γ = 0.286
  t=10: γ = 0.167
  t=50: γ = 0.038  ← 后期小步长精调
```

## 7. Bregman 投影与迭代比例拟合

> 源码: `src/core/bregman-projection.ts`

### 7.1 问题定义

```
min  D_KL(μ || θ)
μ∈M

找到在边际多面体 M 内与市场价格 θ KL 距离最近的点
```

### 7.2 迭代比例拟合 (IPF) 算法

```
┌─────────────────────────────────────────────────────────┐
│               迭代比例拟合 (IPF)                         │
│                                                         │
│  初始: μ = 均匀分布 [1/n, 1/n, ..., 1/n]               │
│                                                         │
│  for iter = 0, 1, 2, ...:                              │
│    for 每个等式约束 (Σ cᵢ·μᵢ = rhs):                   │
│                                                         │
│      ① 计算当前值:  current = Σ cᵢ · μᵢ                │
│                                                         │
│      ② 计算比率:    ratio = rhs / current               │
│                                                         │
│      ③ 乘法更新:    μᵢ ← μᵢ × ratio^(cᵢ)              │
│                                                         │
│    收敛检查: ||μ_new - μ_old||₂ < tolerance             │
│                                                         │
│  输出: μ (投影), D_KL(μ || θ)                           │
└─────────────────────────────────────────────────────────┘
```

### 7.3 为什么用乘法更新？

```
性质 1: 保持非负性
  μᵢ > 0, ratio > 0  →  μᵢ × ratio^c > 0  ✓

性质 2: 满足约束
  约束: μ₁ + μ₂ = 1
  当前: μ₁ + μ₂ = 0.8
  ratio = 1 / 0.8 = 1.25
  更新后: 1.25·μ₁ + 1.25·μ₂ = 1.25·0.8 = 1.0  ✓

性质 3: 比例保持
  更新前 μ₁/μ₂ 的比率 = 更新后 μ₁/μ₂ 的比率
  → 最小化 KL 散度（等效于保持相对比例不变）
```

**数值例子**：

```
θ = [0.30, 0.70, 0.55, 0.45]
约束: μ₁+μ₂ = 1, μ₃+μ₄ = 1
初始: μ = [0.25, 0.25, 0.25, 0.25]

迭代 1:
  约束 1: current = 0.25+0.25 = 0.50, ratio = 1/0.50 = 2.0
          μ₁ = 0.25 × 2.0 = 0.50
          μ₂ = 0.25 × 2.0 = 0.50
  约束 2: current = 0.25+0.25 = 0.50, ratio = 1/0.50 = 2.0
          μ₃ = 0.25 × 2.0 = 0.50
          μ₄ = 0.25 × 2.0 = 0.50

  μ = [0.50, 0.50, 0.50, 0.50]  (满足约束但还没接近 θ)

... 继续迭代（结合 θ 的信息）...

最终: μ ≈ [0.30, 0.70, 0.55, 0.45]  (当 θ 本身合法时)
```

### 7.4 利润保证

```
保证利润 = D_KL(μ̂ || θ) - FW_gap

  D_KL > 0 且 gap 小  →  有利可图
  D_KL ≈ gap         →  利润太小，不值得交易
  D_KL < gap         →  不确定是否有利润

判断条件:
  isProfitable = (D_KL - gap) ≥ MIN_PROFIT_THRESHOLD  (默认 0.05)
```

### 7.5 KL 散度的梯度

```
∇_μ D_KL(μ || θ) = log(μ/θ) + 1

分量形式: ∂D_KL/∂μᵢ = log(μᵢ/θᵢ) + 1

例子: μᵢ = 0.6, θᵢ = 0.4
      梯度 = log(0.6/0.4) + 1 = 0.405 + 1 = 1.405
      → 正梯度意味着减少 μᵢ 可以降低散度
```

## 8. 订单簿力学

> 源码: `src/market/order-book.ts`

### 8.1 订单簿结构

```
        卖单 (Asks) - 递增排列
        ┌────────────────────────┐
$0.58   │████████████████ 200    │  ← Level 3
$0.55   │██████████ 120          │  ← Level 2
$0.52   │████ 50                 │  ← Best Ask (最佳卖价)
        ├────────────────────────┤
        │    Spread = $0.04      │  ← 买卖价差
        ├────────────────────────┤
$0.48   │██████ 80               │  ← Best Bid (最佳买价)
$0.45   │████████████ 150        │  ← Level 2
$0.42   │██████████████ 180      │  ← Level 3
        └────────────────────────┘
        买单 (Bids) - 递减排列
```

### 8.2 中间价（Mid Price）

```
midPrice = (bestBid + bestAsk) / 2

例子: bestBid = $0.48, bestAsk = $0.52
      midPrice = ($0.48 + $0.52) / 2 = $0.50
```

### 8.3 买卖价差（Spread）

```
spread = bestAsk - bestBid

例子: spread = $0.52 - $0.48 = $0.04 (4%)
```

### 8.4 VWAP（成交量加权平均价格）

当你买入大量时，不能只按 Best Ask 成交，需要"吃掉"多层卖单：

```
VWAP = Σ(sizeᵢ × priceᵢ) / Σ(sizeᵢ)

例子: 买入 200 份

  Level 1: $0.52 × 50  = $26.00  (吃完 50 份)
  Level 2: $0.55 × 120 = $66.00  (吃完 120 份)
  Level 3: $0.58 × 30  = $17.40  (部分成交 30 份，凑满 200)
  ─────────────────────────────
  总花费: $109.40
  总量:   200 份
  VWAP:   $109.40 / 200 = $0.547

  对比 Best Ask: $0.52
  VWAP 比 Best Ask 贵了 $0.027/份
```

### 8.5 滑点（Slippage）

```
买入滑点 = (VWAP - midPrice) / midPrice
卖出滑点 = (midPrice - VWAP) / midPrice

例子: midPrice = $0.50, 买入 VWAP = $0.547
      slippage = ($0.547 - $0.50) / $0.50 = 9.4%
```

### 8.6 流动性失衡（Imbalance）

```
imbalance = (askDepth - bidDepth) / (askDepth + bidDepth)

例子:
  bidDepth = 80 + 150 + 180 = 410
  askDepth = 50 + 120 + 200 = 370

  imbalance = (370 - 410) / (370 + 410) = -40/780 = -0.051

  解读: 略微偏向买方（卖单较少）
        imbalance ∈ [-1, 1]
        > 0: 卖压大
        < 0: 买压大
        ≈ 0: 平衡
```

### 8.7 最大可执行量

```
遍历价格层级，累积直到滑点超过容忍度:

  maxSize = 0
  for 每层 level:
    currentVWAP = updateVWAP(level)
    currentSlippage = (currentVWAP - mid) / mid
    if currentSlippage > SLIPPAGE_TOLERANCE:
      // 线性插值计算精确的最大量
      break
    maxSize += level.size
```

## 9. 做市策略数学

> 源码: `src/strategies/market-making.ts`

### 9.1 公允价值：微观价格（Microprice）

传统中间价对双方同等加权，微观价格根据**挂单量**加权：

```
标准中间价:
  mid = (bid + ask) / 2

微观价格:
  bidWeight = 1 / bidSize  (小挂单量 → 权重大，意味着该价格更脆弱)
  askWeight = 1 / askSize
  microPrice = (bid × askWeight + ask × bidWeight) / (bidWeight + askWeight)
```

**直觉**：如果卖方挂单很少，价格更可能上涨，所以公允值更偏向卖方。

```
例子:
  bestBid = $0.48, bidSize = 200
  bestAsk = $0.52, askSize = 50

  标准中间价 = ($0.48 + $0.52) / 2 = $0.500

  bidWeight = 1/200 = 0.005
  askWeight = 1/50  = 0.020
  microPrice = ($0.48 × 0.020 + $0.52 × 0.005) / (0.005 + 0.020)
             = ($0.0096 + $0.0026) / 0.025
             = $0.0122 / 0.025
             = $0.488

  微观价格 ($0.488) < 中间价 ($0.500)
  → 因为卖单少，价格更可能向上移动...
  → 等等，这里卖单少应该偏高才对

  重新检查: 公式用反向权重
  microPrice = (bid × askWeight + ask × bidWeight)
  bid 的权重是 askWeight (对面的) → 卖单少 → askWeight 大 → bid 权重大
  → microPrice 偏向 bid 方向

  实际源码逻辑: 挂单少 = 更容易被吃掉 = 价格更不稳定
```

### 9.2 EMA 平滑

```
fairValue = α × microPrice + (1-α) × prevFairValue

α = 0.3 (平滑因子)

作用: 避免公允值因单笔大单突变而剧烈波动

时间序列:
  t=1: micro=0.50, fair = 0.3×0.50 + 0.7×0.50 = 0.500
  t=2: micro=0.55, fair = 0.3×0.55 + 0.7×0.50 = 0.515
  t=3: micro=0.53, fair = 0.3×0.53 + 0.7×0.515 = 0.520
  t=4: micro=0.48, fair = 0.3×0.48 + 0.7×0.520 = 0.508
```

### 9.3 库存偏移报价

```
halfSpread = targetSpread / 2

skew = clamp(inventory / maxInventory, -1, 1)
skewOffset = skew × inventorySkew × halfSpread

对每层报价 i (i = 0, 1, 2, ...):
  levelSpread = halfSpread × (1 + i × 0.5)
  size = orderSize × sizeIncrement^i

  bidPrice = fairValue × (1 - levelSpread + skewOffset)
  askPrice = fairValue × (1 + levelSpread + skewOffset)
```

**图解**：

```
  库存 = 0 (中性):                    库存 = +50 (多头过多):
  ┌─────────┬─────────┐              ┌──────────┬────────┐
  │  买单    │  卖单    │              │  买单     │  卖单   │
  │         │         │              │          │        │
  │ ←─ 对称 ─→        │              │ ←── 偏移 ──→       │
  │         │         │              │          │        │
  │   fair  │         │              │   fair   │        │
  └─────────┴─────────┘              └──────────┴────────┘
  bid=0.49  mid=0.50  ask=0.51       bid=0.485 mid=0.50  ask=0.505
                                     ↑ 买单更远: 不想再买入
                                     ↑ 卖单更近: 积极卖出减仓
```

**数值例子**：

```
fairValue = 0.50
targetSpread = 0.02, halfSpread = 0.01
inventory = 30, maxInventory = 100
inventorySkew = 0.5

skew = 30/100 = 0.3
skewOffset = 0.3 × 0.5 × 0.01 = 0.0015

Level 0 (i=0):
  levelSpread = 0.01 × (1 + 0) = 0.01
  bidPrice = 0.50 × (1 - 0.01 + 0.0015) = 0.50 × 0.9915 = 0.4958
  askPrice = 0.50 × (1 + 0.01 + 0.0015) = 0.50 × 1.0115 = 0.5058
  size = 10

Level 1 (i=1):
  levelSpread = 0.01 × (1 + 0.5) = 0.015
  bidPrice = 0.50 × (1 - 0.015 + 0.0015) = 0.50 × 0.9865 = 0.4933
  askPrice = 0.50 × (1 + 0.015 + 0.0015) = 0.50 × 1.0165 = 0.5083
  size = 10 × 1.5 = 15
```

## 10. Kelly 准则与仓位管理

> 源码: `src/execution/position-sizing.ts`

### 10.1 标准 Kelly 公式

**问题**: 你认为某个结果概率为 p，但市场价格为 θ。应该押多少？

```
f = (b·p - q) / b

其中:
  f = 资金比例（应投入多少）
  b = 赔率 = (1-θ)/θ （买入时）或 θ/(1-θ)（卖出时）
  p = 你认为的真实概率
  q = 1 - p = 失败概率
```

**图解**：

```
赔率 b 的含义:

  你花 θ 买一个代币
  如果赢了，得到 $1，净利润 = 1-θ
  如果输了，失去 θ

  赔率 b = 净利润/投入 = (1-θ)/θ

  θ = 0.40 → b = 0.60/0.40 = 1.5 (赔率 1.5:1)
  θ = 0.70 → b = 0.30/0.70 = 0.43
  θ = 0.20 → b = 0.80/0.20 = 4.0 (赔率 4:1)
```

### 10.2 修正 Kelly

标准 Kelly 最大化**长期增长率**，但波动大。项目使用修正版本：

```
第 1 步: 标准 Kelly
  f = (b·p - q) / b

第 2 步: 乘以 √p（保守调整）
  f_modified = f × √p

第 3 步: 乘以安全系数 (默认 0.25)
  f_final = f_modified × KELLY_FRACTION
```

**为什么乘以 √p ？**

```
p 较大时 √p ≈ 1，几乎不变
p 较小时 √p << 1，大幅缩减

  p = 0.90 → √p = 0.949 → 减少 5%
  p = 0.60 → √p = 0.775 → 减少 22%
  p = 0.30 → √p = 0.548 → 减少 45%

直觉: 低概率事件即使有正期望值，也应该少押
     因为你对概率估计的不确定性更大
```

### 10.3 完整数值例子

```
场景: 你认为 YES 概率 = 75%，但市场价格 = 60%
     资本 = $10,000

  b = (1 - 0.60) / 0.60 = 0.667
  p = 0.75, q = 0.25

  标准 Kelly:
    f = (0.667 × 0.75 - 0.25) / 0.667
    f = (0.500 - 0.25) / 0.667
    f = 0.375                           → $3,750

  修正 Kelly:
    f = 0.375 × √0.75
    f = 0.375 × 0.866
    f = 0.325                           → $3,250

  最终 (×0.25):
    f = 0.325 × 0.25
    f = 0.081                           → $810

  约束检查:
    MAX_BET_FRACTION (10%): $1,000 > $810  ✓
    流动性限制: 假设 $5,000 可用   > $810  ✓
    风险限制: 假设 $2,000          > $810  ✓

  最终仓位 = $810
```

### 10.4 期望值计算

```
买入时:
  EV = size × [p × (1-θ) - (1-p) × θ]
     = 赢的期望 - 输的期望

卖出时:
  EV = size × [(1-p) × θ - p × (1-θ)]

例子 (接上):
  EV = $810 × [0.75 × 0.40 - 0.25 × 0.60]
     = $810 × [0.30 - 0.15]
     = $810 × 0.15
     = $121.50

  → 每次交易期望利润 $121.50
```

### 10.5 风险调整收益（类 Sharpe 比率）

```
variance = p × (1 - p)
riskAdjustedReturn = EV / (size × √variance)

例子:
  variance = 0.75 × 0.25 = 0.1875
  riskAdjustedReturn = $121.50 / ($810 × √0.1875)
                     = $121.50 / ($810 × 0.433)
                     = $121.50 / $350.73
                     = 0.346
```

### 10.6 单市场套利仓位

```
当 YES + NO < 1 时:

  profitPerUnit = 1 - (YES + NO)
  size = min(流动性限制, 资金限制)
  资金限制 = (capital × MAX_BET_FRACTION) / (YES + NO)

例子:
  YES = $0.45, NO = $0.48, 总和 = $0.93
  capital = $10,000

  profitPerUnit = 1 - 0.93 = $0.07
  资金限制 = ($10,000 × 0.10) / 0.93 = $1,075
  流动性限制 = min(YES 深度, NO 深度) × 0.50 = 500 × 0.50 = 250

  size = min(250, 1075) = 250 份
  expectedProfit = 250 × $0.07 = $17.50
```

## 11. 技术分析指标

> 源码: `src/strategies/trend-following.ts`

### 11.1 简单移动平均 (SMA)

```
SMA(N) = (P₁ + P₂ + ... + Pₙ) / N

例子 (N=5):
  价格序列: [0.50, 0.52, 0.51, 0.54, 0.53]
  SMA(5) = (0.50 + 0.52 + 0.51 + 0.54 + 0.53) / 5 = 0.52

  新价格 0.56 到来:
  SMA(5) = (0.52 + 0.51 + 0.54 + 0.53 + 0.56) / 5 = 0.532
```

### 11.2 指数移动平均 (EMA)

对近期价格给予更多权重：

```
multiplier = 2 / (period + 1)
EMA_t = (Price_t - EMA_{t-1}) × multiplier + EMA_{t-1}

等价形式:
EMA_t = multiplier × Price_t + (1 - multiplier) × EMA_{t-1}
```

**权重衰减图**：

```
  权重
  ↑
  │  ██
  │  ██ ██
  │  ██ ██ ██
  │  ██ ██ ██ ██
  │  ██ ██ ██ ██ ██
  │  ██ ██ ██ ██ ██ ██ ██ ██ ██ ██
  └──────────────────────────────── → 时间
     今天  1天前  2天前  ...  N天前

  EMA 对最近的价格反应更快
  SMA 对所有价格同等对待
```

**数值例子 (period=5, multiplier=0.333)**：

```
  t=1: Price=0.50, EMA = 0.50
  t=2: Price=0.52, EMA = 0.333×0.52 + 0.667×0.50 = 0.5067
  t=3: Price=0.51, EMA = 0.333×0.51 + 0.667×0.5067 = 0.5078
  t=4: Price=0.54, EMA = 0.333×0.54 + 0.667×0.5078 = 0.5185
  t=5: Price=0.53, EMA = 0.333×0.53 + 0.667×0.5185 = 0.5224
```

### 11.3 相对强弱指数 (RSI)

衡量**超买/超卖**程度：

```
RS = avgGain / avgLoss
RSI = 100 - 100 / (1 + RS)

RSI ∈ [0, 100]
  RSI > 70: 超买 → 可能回调（看跌信号）
  RSI < 30: 超卖 → 可能反弹（看涨信号）
```

**数值例子 (period=5)**：

```
价格序列: [0.50, 0.52, 0.51, 0.54, 0.53, 0.56]

变化: [+0.02, -0.01, +0.03, -0.01, +0.03]

gains  = 0.02 + 0.03 + 0.03 = 0.08
losses = 0.01 + 0.01         = 0.02

avgGain = 0.08 / 5 = 0.016
avgLoss = 0.02 / 5 = 0.004

RS = 0.016 / 0.004 = 4.0
RSI = 100 - 100/(1+4) = 100 - 20 = 80

→ RSI = 80 > 70 → 超买! 谨慎买入
```

**RSI 状态图**：

```
  100 ┬─────────────────────────
      │         超买区域
   70 ┤═════════════════════════  ← 超买线
      │
      │         中性区域
      │
   30 ┤═════════════════════════  ← 超卖线
      │         超卖区域
    0 ┴─────────────────────────
```

### 11.4 趋势判定

```
短期 SMA vs 长期 SMA:

  if shortSMA > longSMA × 1.01:  趋势 = 上涨
  if shortSMA < longSMA × 0.99:  趋势 = 下跌
  否则:                           趋势 = 中性

趋势强度:
  trendDiff = |shortSMA - longSMA| / longSMA
  strength = min(1, trendDiff × 10)

例子:
  shortSMA = 0.55, longSMA = 0.50
  0.55 > 0.50 × 1.01 = 0.505?  是 → 上涨趋势
  trendDiff = |0.55 - 0.50| / 0.50 = 0.10
  strength = min(1, 0.10 × 10) = 1.0  → 最强趋势!
```

### 11.5 交易信号生成

```
  ┌────────────────────────────────────────────────┐
  │              信号生成决策树                       │
  │                                                │
  │  趋势 = UP ?                                    │
  │    ├── YES + RSI < 70 (未超买) → 买入信号         │

  │                                                │
  │  趋势 = NEUTRAL → 不操作                         │

  │  额外条件: strength ≥ minTrendStrength (0.3)     │
  └────────────────────────────────────────────────┘
```

## 12. 风险管理数学

> 源码: `src/execution/risk-manager.ts`

### 12.1 已实现盈亏 (Realized PnL)

```
多头 (LONG):
  PnL = exitSize × exitPrice - entrySize × entryPrice

空头 (SHORT):
  PnL = entrySize × entryPrice - exitSize × exitPrice

例子:
  买入 100 份 @ $0.45，卖出 100 份 @ $0.52
  PnL = 100 × $0.52 - 100 × $0.45
      = $52 - $45 = $7 利润
```

### 12.2 未实现盈亏 (Unrealized PnL)

```
unrealizedPnL = Σ (markPrice - avgPrice) × size

例子:
  持仓 1: 50 份 @ $0.40, 当前价 $0.48 → (0.48-0.40)×50 = $4.00
  持仓 2: 30 份 @ $0.55, 当前价 $0.52 → (0.52-0.55)×30 = -$0.90
  ──────────────────────────────────
  总未实现 PnL = $4.00 + (-$0.90) = $3.10
```

### 12.3 持仓均价更新

```
newAvgPrice = (oldSize × oldAvgPrice + newSize × newPrice) / totalSize

例子:
  原持仓: 100 份 @ $0.45
  新买入: 50 份 @ $0.50

  newAvg = (100 × $0.45 + 50 × $0.50) / 150
         = ($45 + $25) / 150
         = $0.467
```

### 12.4 总敞口

```
totalExposure = Σ |sizeᵢ × avgPriceᵢ|

例子:
  持仓 A: 100 份 @ $0.45  → $45
  持仓 B: -50 份 @ $0.60  → $30  (绝对值)
  ─────────────────────────
  totalExposure = $45 + $30 = $75
```

### 12.5 持仓集中度

```
concentration = |newPositionSize × unitValue| / totalExposure

规则: concentration > 0.5 → 拒绝交易 (风险等级: medium)
```

## 13. 信号聚合

> 源码: `src/strategies/signal-aggregation.ts`

### 13.1 优先级聚合

```
选择置信度最高的信号:

  信号 A: confidence = 0.72, price = $0.48
  信号 B: confidence = 0.85, price = $0.51  ← 选这个
  信号 C: confidence = 0.60, price = $0.49
```

### 13.2 加权聚合

```
avgPrice = Σ(priceᵢ × confidenceᵢ) / Σ(confidenceᵢ)
avgSize = Σ(sizeᵢ × confidenceᵢ) / Σ(confidenceᵢ)
avgConfidence = Σ(confidenceᵢ) / count

方向决定:
  buyWeight = Σ(confidenceᵢ) for 所有买入信号
  sellWeight = Σ(confidenceᵢ) for 所有卖出信号
  direction = buyWeight ≥ sellWeight ? BUY : SELL

例子:
  信号 1: BUY,  price=$0.48, confidence=0.80
  信号 2: BUY,  price=$0.50, confidence=0.60
  信号 3: SELL, price=$0.52, confidence=0.70

  buyWeight = 0.80 + 0.60 = 1.40
  sellWeight = 0.70
  direction = BUY ✓

  avgPrice = (0.48×0.80 + 0.50×0.60 + 0.52×0.70) / (0.80+0.60+0.70)
           = (0.384 + 0.300 + 0.364) / 2.10
           = $0.499
```

### 13.3 共识聚合

```
consensus = agreementCount / totalStrategies

只有当共识 ≥ minConsensus 时才交易:

例子 (minConsensus = 0.6):
  策略 A: BUY
  策略 B: BUY
  策略 C: SELL
  策略 D: BUY
  策略 E: 无信号

  BUY 共识 = 3/5 = 0.60 ≥ 0.60 → 可以交易
  SELL 共识 = 1/5 = 0.20 < 0.60 → 不行

  最终: 按 BUY 组的加权平均生成信号
```

## 附录 B: 单纯形投影算法

> 源码: `src/utils/math.ts` (L294-318)

将任意向量投影到概率单纯形（Σxᵢ = 1, xᵢ ≥ 0）：

```
算法:
  1. 排序: sorted = sort(v, descending)
  2. 找阈值:
     for i = 0 to n-1:
       cumsum += sorted[i]
       if sorted[i] > (cumsum - 1) / (i + 1):
         ρ = i
  3. 计算 λ = (cumsum - 1) / (ρ + 1)
  4. 投影: result[i] = max(v[i] - λ, 0)

数值例子:
  v = [0.6, -0.1, 0.3, 0.4]
  sorted = [0.6, 0.4, 0.3, -0.1]

  i=0: cumsum=0.6, 0.6 > (0.6-1)/1 = -0.4? 是 → ρ=0
  i=1: cumsum=1.0, 0.4 > (1.0-1)/2 = 0.0?  是 → ρ=1
  i=2: cumsum=1.3, 0.3 > (1.3-1)/3 = 0.1?  是 → ρ=2
  i=3: cumsum=1.2, -0.1>(1.2-1)/4 = 0.05? 否

  λ = (1.3 - 1) / (2 + 1) = 0.1

  result = [max(0.6-0.1,0), max(-0.1-0.1,0), max(0.3-0.1,0), max(0.4-0.1,0)]
         = [0.5, 0, 0.2, 0.3]

  验证: 0.5 + 0 + 0.2 + 0.3 = 1.0 ✓
        所有元素 ≥ 0 ✓
```

## 附录 C: 百分位计算

> 源码: `src/utils/percentile.ts`

```
线性插值法:

  index = (percentile / 100) × (length - 1)
  lowerIndex = floor(index)
  upperIndex = ceil(index)
  weight = index - lowerIndex
  result = lower × (1 - weight) + upper × weight

例子 (求第 75 百分位):
  sorted data = [10, 20, 30, 40, 50]
  index = (75/100) × (5-1) = 3.0
  lowerIndex = 3, upperIndex = 3
  result = 40

例子 (求第 60 百分位):
  index = (60/100) × (5-1) = 2.4
  lowerIndex = 2, upperIndex = 3
  weight = 0.4
  result = 30 × 0.6 + 40 × 0.4 = 34
```
